# Image Processing

Fundamentals and applied projects in digital image processing — classical methods alongside modern deep learning approaches.

## Projects

| # | Project | Description |
|---|---------|-------------|
| 1 | **ANPR (Number Plate Recognition)** | Hybrid YOLO + traditional pipeline for automatic number plate recognition |
| 2 | **Spatial Filtering** | Gaussian, median, bilateral filters; edge detection |
| 3 | **Frequency Domain** | Fourier transform, low/high-pass filters, noise removal |
| 4 | **Morphological Operations** | Erosion, dilation, opening, closing, skeletonisation |
| 5 | **Colour Spaces** | RGB, HSV, LAB transformations and applications |

## Tech Stack

Python · OpenCV · NumPy · scikit-image · Matplotlib · YOLOv8 · Jupyter Notebook

## Key Concepts

Spatial & Frequency Domain Filtering · Morphological Processing · Colour Space Transformations · Object Detection · Thresholding · Histogram Equalisation
