# 01 — Fundamentals

Image representation and basic transforms — the building blocks for everything else in this repo.

## `image_basics.ipynb`

- Reading images with OpenCV and Pillow, and the BGR vs RGB difference
- Inspecting shape, dtype, and channel count
- Grayscale conversion
- Resize, crop, rotate (`cv2.getRotationMatrix2D` + `warpAffine`), and flip
- Color space conversion: RGB → HSV, viewing each channel separately

## Tech Stack

Python · OpenCV · Pillow · NumPy · Matplotlib
